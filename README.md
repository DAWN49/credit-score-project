# Credit Scoring ML Project

## Бизнес-задача

Разработка модели машинного обучения для предсказания вероятности дефолта (невозврата) кредита. 

Цель — минимизировать финансовые потери банка от выдачи плохих кредитов.

## Данные

Датасет German Credit Data (1000 записей, 21 признак). 

Целевая переменная: `credit_risk` (1 - хороший клиент, 0 - дефолт).

Дисбаланс классов: 70% / 30%.

## Ход работы

1. **EDA**: Выявлены ключевые предикторы. Например, срок кредита `duration`) сильно коррелирует с риском дефолта (медиана 24 мес у плохих, 18 мес у хороших).

2. **Preprocessing**: 

   * Применен One-Hot Encoding для категориальных признаков.

   * Использован `StandardScaler` для логистической регрессии.

   * Для CatBoost применены нативные категориальные признаки `cat_features`).

3. **Моделирование**: 

   * Обучил `LogisticRegression` (ROC-AUC: 0.7514).

   * Обучил `CatBoostClassifier` (ROC-AUC: 0.7719).

4. **Оптимизация порога**: Подобрал порог классификации, максимизирующий F1-score, чтобы найти баланс между Precision и Recall.

## Стек

Python, Pandas, Scikit-learn, CatBoost, Matplotlib, Seaborn.
